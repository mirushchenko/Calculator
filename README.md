# Neo Calculator

A modern, responsive calculator built with pure HTML, CSS and JavaScript.

[**Live Demo**](https://mirushchenko.github.io/Calculator/)

## Features

- **Basic Operations**: +, -, ×, ÷
- **Responsive Design**: Works on desktop and mobile
- **Keyboard Support**: Use your keyboard to calculate
- **Modern UI**: Glass-morphism design with smooth animations
- **Error Handling**: Prevents division by zero and other errors

## Quick Start

1. Download or clone this repository
2. Open `index.html` in your browser
3. Start calculating!

## Keyboard Shortcuts

- `0-9` - Numbers
- `+ - * /` - Operations  
- `Enter` or `=` - Calculate
- `Escape` - Clear
- `.` - Decimal point

## Built With

- HTML5
- CSS3 (Grid & Flexbox)
- Vanilla JavaScript

## Responsive

Fully responsive design that works on:
- Desktop computers
- Tablets
- Mobile phones
